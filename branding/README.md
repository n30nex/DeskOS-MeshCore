# DeskOS brand assets

DeskOS uses the bright MeshCore palette established by
[NeonPocketMC](https://github.com/n30nex/NeonPocketMC) while keeping its own
touch-display mark.

## Palette

| Role | Hex |
|---|---|
| Electric cyan | `#20D9ED` |
| Cobalt | `#1E5AEF` |
| Neon lime | `#84FF2E` |
| Charcoal | `#17191A` |
| Main text | `#F4F7FB` |

## Files

- `deskos-mark.png`: 1024 px transparent master.
- `deskos-mark-512.png`: repository and documentation artwork.
- `deskos-mark-128.png`: compact project artwork.
- `deskos-mark-64.png`: small icon artwork.

Keep the mark on a plain charcoal or transparent background. Leave at least
one eighth of its width as clear space. Do not add text, gradients, boxes, or
extra effects around it.

## Provenance

The original bitmap was generated with OpenAI ImageGen using the NeonPocketMC
mark as a palette and visual-family reference. The brief requested a distinct,
text-free DeskOS touch-display mark containing a three-node mesh and outgoing
packet sparks in electric cyan, cobalt, neon lime, and charcoal. The selected
result was mechanically trimmed, transparency-normalized, centered, and
resized into the production files above.
